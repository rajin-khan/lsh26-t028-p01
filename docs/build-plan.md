# KajChole build plan

## Agent actions

1. Implement and unit-test interval normalization and deterministic scheduling.
2. Build the single-screen planner and 24-hour timeline.
3. Add editing, removal, sample reset, local persistence, validation, and empty states.
4. Add English and Bangla interface copy if it does not threaten the four core flows.
5. Complete README, evaluation manifest, licenses, and deployment metadata.
6. Run type, build, functional, responsive, and accessibility checks.
7. Commit stable milestones with clear messages.

## User actions

No user action is needed for local implementation.

When the judged build is ready, the team leader must:

1. Create or confirm the hosting project for this repository.
2. Make the GitHub repository public.
3. Open the live URL in a private browser window and run the demo checklist.
4. Copy the exact 40-character SHA of the judged commit.
5. Submit the public repository URL, judged SHA, and live URL in the final submission form.

The agent can prepare the code, docs, commits, and deployment configuration. The user controls account access, repository visibility, and the final submission form.
